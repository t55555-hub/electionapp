# ElectionApp

ElectionApp is a modern Android app concept designed to help voters prepare for election day with less stress and more clarity. The app focuses on simple planning, ballot tracking, readiness checks, and support resources for common voting issues.

This project was created as a UI/UX case study and Android Studio prototype.

## Features

- Clean login / onboarding screen
- Home dashboard with voter readiness status
- Visit planner with recommended timing and polling place details
- Ballot tracker timeline
- MyHub profile and preferences section
- Documentation / help section for common voter issues
- Modern UI built with Jetpack Compose

## Screens

- **Login**
- **Home**
- **Planner**
- **Tracker**
- **MyHub**
- **Documentation**

## Tech Stack

- **Kotlin**
- **Jetpack Compose**
- **Material 3**
- **Android Studio**

## Project Goal

The goal of ElectionApp is to explore how a mobile product could make voting feel more organized, accessible, and less confusing. Rather than acting as a political product, this app is designed as a neutral voter-support tool.
